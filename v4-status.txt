  New Capabilities:
  - kpu.set_fidelity(kpu.TRANSACTIONAL) enables C++ timing simulation
  - Detailed cycle breakdown: compute, memory, busy, idle, stall
  - Performance metrics: GFLOPS, utilization, efficiency
  - MNIST MLP verified with transactional timing (~409 GFLOPS, 17K cycles for batch-32)

  Remaining for v0.4.x:
  - TransactionalMemoryController integration (memory timing)
  - Configuration API for array size, clock frequency
  - Additional operator support in native code (conv2d, pooling, etc.)
