  - tests/timing/test_streamer_process.cpp - 18 test cases
  - tests/timing/test_component_integration.cpp - 9 integration test cases

  Key Features Implemented

  1. StreamerProcess - L2↔L1/Compute transfers
    - Feed operations (L2→Compute)
    - Drain operations (Compute→L2)
    - Row and Column streamer types
  2. Work-Conserving Scan - Prevents head-of-line blocking
    - Scans entire queue for any ready work
    - Processes tiles that arrive out of order
    - Implemented in BlockMoverProcess and StreamerProcess
  3. Priority Aging - Prevents starvation
    - Optional config flag priority_aging
    - Prefers oldest ready tile (by enqueue_cycle)
    - Ensures old requests aren't starved by newer ones
  4. Integration Tests - Full pipeline verification
    - DMA → BlockMover pipeline
    - BlockMover → Streamer pipeline
    - Full round-trip: load → compute → drain → store
    - Credit flow tests with limited buffers
    - Multi-component parallel tests
