# v0.7 C++ Quantization Design

## Overview

This document describes the template-based quantization architecture for the KPU simulator
that leverages Universal library scalar types. The key insight is that properly parameterized
kernels can be specialized to any quantized type without code changes.

## Design Principles

1. **Template-first**: All kernels are `template<typename Scalar>`
2. **Universal types**: Use sw::universal for FP16, BF16, FP8 variants, FP4
3. **Native types**: Use std::int32_t, std::int16_t, std::int8_t for integers
4. **Packed storage**: INT4/FP4 use packed storage with Q/DQ conversion at boundaries
5. **Accumulator promotion**: Automatic accumulator type selection via traits

### 2. Packed Type Support (INT4, FP4)

```cpp
// include/sw/kpu/quantization/packed_types.hpp

namespace sw::kpu {

/// INT4 packed storage: 2 elements per byte
/// High nibble = even index, Low nibble = odd index
struct PackedInt4 {
    std::uint8_t data;

    /// Extract element at index (0 or 1)
    constexpr std::int8_t get(size_t idx) const {
        std::int8_t val = (idx == 0)
            ? static_cast<std::int8_t>((data >> 4) & 0x0F)
            : static_cast<std::int8_t>(data & 0x0F);
        // Sign extend from 4 bits
        return (val & 0x08) ? (val | 0xF0) : val;
    }

    /// Set element at index (0 or 1)
    constexpr void set(size_t idx, std::int8_t val) {
        val &= 0x0F;  // Mask to 4 bits
        if (idx == 0) {
            data = (data & 0x0F) | (val << 4);
        } else {
            data = (data & 0xF0) | val;
        }
    }
};

/// Unpacked INT4 for kernel computation (1 element per byte)
struct Int4Unpacked {
    std::int8_t value;  // Only lower 4 bits valid, sign-extended

    constexpr Int4Unpacked() : value(0) {}
    constexpr Int4Unpacked(std::int8_t v) : value(v) {}

    // Arithmetic operations use int8 internally
    constexpr Int4Unpacked operator+(Int4Unpacked rhs) const {
        return Int4Unpacked(value + rhs.value);
    }
    constexpr Int4Unpacked operator*(Int4Unpacked rhs) const {
        return Int4Unpacked(value * rhs.value);
    }
};

/// Q/DQ conversion for packed types
template<typename Packed, typename Unpacked>
class PackedConverter {
public:
    /// Dequantize: Packed storage → Unpacked for computation
    static void dequantize(const Packed* src, Unpacked* dst, size_t count);

    /// Quantize: Unpacked result → Packed storage
    static void quantize(const Unpacked* src, Packed* dst, size_t count);
};

} // namespace sw::kpu
```

### 3. Template Kernel Interface

```cpp
// include/sw/kpu/quantization/kernels.hpp

namespace sw::kpu::kernels {

/// Tensor view for kernel operations
template<typename Scalar>
struct TensorView {
    Scalar* data;
    size_t rows;
    size_t cols;
    size_t stride;  // Row stride in elements

    Scalar& operator()(size_t i, size_t j) {
        return data[i * stride + j];
    }
    const Scalar& operator()(size_t i, size_t j) const {
        return data[i * stride + j];
    }
};

/// Matrix multiplication kernel with explicit accumulator type
/// C = alpha * A @ B + beta * C
///
/// Two type parameters enable:
/// - Same-type: matmul<int8_t, int32_t>(A, B, C) for INT8 with INT32 accumulator
/// - Mixed-precision: matmul<int8_t, float>(A, B, C) for INT8 inputs, FP32 accumulator
/// - Energy optimization: matmul<bf16_t, bf16_t>(A, B, C) for full BF16 pipeline
template<typename Scalar, typename Accumulator>
void matmul(
    const TensorView<Scalar>& A,  // [M x K]
    const TensorView<Scalar>& B,  // [K x N]
    TensorView<Accumulator>& C,   // [M x N] - explicit accumulator type
    Accumulator alpha = Accumulator(1),
    Accumulator beta = Accumulator(0)
) {
    for (size_t i = 0; i < A.rows; ++i) {
        for (size_t j = 0; j < B.cols; ++j) {
            Accumulator sum = beta * C(i, j);
            for (size_t k = 0; k < A.cols; ++k) {
                // Explicit conversion to accumulator type
                sum += static_cast<Accumulator>(A(i, k)) * static_cast<Accumulator>(B(k, j));
            }
            C(i, j) = alpha * sum;
        }
    }
}

/// Mixed-precision matmul: different types for A and B
/// Useful for weight-only quantization (INT8 weights, FP32 activations)
template<typename ScalarA, typename ScalarB, typename Accumulator>
void matmul_mixed(
    const TensorView<ScalarA>& A,  // [M x K] - e.g., FP32 activations
    const TensorView<ScalarB>& B,  // [K x N] - e.g., INT8 weights
    TensorView<Accumulator>& C,    // [M x N]
    Accumulator alpha = Accumulator(1),
    Accumulator beta = Accumulator(0)
) {
    for (size_t i = 0; i < A.rows; ++i) {
        for (size_t j = 0; j < B.cols; ++j) {
            Accumulator sum = beta * C(i, j);
            for (size_t k = 0; k < A.cols; ++k) {
                sum += static_cast<Accumulator>(A(i, k)) * static_cast<Accumulator>(B(k, j));
            }
            C(i, j) = alpha * sum;
        }
    }
}

/// Elementwise operations
template<typename Scalar>
void add(
    const TensorView<Scalar>& A,
    const TensorView<Scalar>& B,
    TensorView<Scalar>& C,
    size_t count
) {
    for (size_t i = 0; i < count; ++i) {
        C.data[i] = A.data[i] + B.data[i];
    }
}

template<typename Scalar>
void relu(TensorView<Scalar>& X, size_t count) {
    for (size_t i = 0; i < count; ++i) {
        if (X.data[i] < Scalar(0)) {
            X.data[i] = Scalar(0);
        }
    }
}

/// Softmax with accumulator promotion
template<typename Scalar>
void softmax(
    const TensorView<Scalar>& X,
    TensorView<Scalar>& Y,
    size_t batch_size,
    size_t dim
) {
    using Acc = typename ScalarTraits<Scalar>::accumulator_type;

    for (size_t b = 0; b < batch_size; ++b) {
        // Find max for numerical stability
        Acc max_val = static_cast<Acc>(X.data[b * dim]);
        for (size_t i = 1; i < dim; ++i) {
            Acc val = static_cast<Acc>(X.data[b * dim + i]);
            if (val > max_val) max_val = val;
        }

        // Compute exp and sum
        Acc sum = Acc(0);
        for (size_t i = 0; i < dim; ++i) {
            Acc exp_val = std::exp(static_cast<Acc>(X.data[b * dim + i]) - max_val);
            Y.data[b * dim + i] = static_cast<Scalar>(exp_val);
            sum += exp_val;
        }

        // Normalize
        for (size_t i = 0; i < dim; ++i) {
            Y.data[b * dim + i] = static_cast<Scalar>(
                static_cast<Acc>(Y.data[b * dim + i]) / sum
            );
        }
    }
}

// ... similar for conv2d, layernorm, batchnorm, pooling

} // namespace sw::kpu::kernels
```

### 4. Quantization Parameters

```cpp
// include/sw/kpu/quantization/quant_params.hpp

namespace sw::kpu {

/// Affine quantization parameters: x_q = round(x / scale) + zero_point
template<typename Scalar>
struct QuantParams {
    float scale;
    int32_t zero_point;

    /// Quantize a float value
    Scalar quantize(float x) const {
        float q = std::round(x / scale) + zero_point;
        q = std::clamp(q,
            static_cast<float>(ScalarTraits<Scalar>::min_value()),
            static_cast<float>(ScalarTraits<Scalar>::max_value()));
        return static_cast<Scalar>(q);
    }

    /// Dequantize to float
    float dequantize(Scalar x_q) const {
        return (static_cast<float>(x_q) - zero_point) * scale;
    }
};

/// Per-channel quantization parameters
template<typename Scalar>
struct PerChannelQuantParams {
    std::vector<float> scales;
    std::vector<int32_t> zero_points;
    size_t num_channels;
    int channel_axis;  // Which axis has channels
};

/// Compute quantization parameters from data range
template<typename Scalar>
QuantParams<Scalar> compute_quant_params(float min_val, float max_val, bool symmetric = false) {
    QuantParams<Scalar> params;

    constexpr float qmin = static_cast<float>(ScalarTraits<Scalar>::min_value());
    constexpr float qmax = static_cast<float>(ScalarTraits<Scalar>::max_value());

    if (symmetric) {
        float abs_max = std::max(std::abs(min_val), std::abs(max_val));
        params.scale = abs_max / qmax;
        params.zero_point = 0;
    } else {
        params.scale = (max_val - min_val) / (qmax - qmin);
        params.zero_point = static_cast<int32_t>(std::round(qmin - min_val / params.scale));
    }

    return params;
}

} // namespace sw::kpu
```

### 5. Compute Fabric Integration

```cpp
// include/sw/kpu/models/behavioral/compute/typed_compute_fabric.hpp

namespace sw::kpu {

/// Type-dispatching compute fabric
class TypedComputeFabric {
public:
    /// Execute matmul with automatic type dispatch
    template<typename Scalar>
    void submit_matmul(
        const Scalar* A, const Scalar* B,
        typename ScalarTraits<Scalar>::accumulator_type* C,
        size_t M, size_t N, size_t K
    ) {
        kernels::TensorView<Scalar> a_view{const_cast<Scalar*>(A), M, K, K};
        kernels::TensorView<Scalar> b_view{const_cast<Scalar*>(B), K, N, N};
        kernels::TensorView<typename ScalarTraits<Scalar>::accumulator_type> c_view{C, M, N, N};

        kernels::matmul(a_view, b_view, c_view);

        // Record XUE events
        uint64_t flops = 2ULL * M * N * K;
        sw::xue::xue().record_matmul(M, N, K, estimate_cycles<Scalar>(flops));
    }

    /// Runtime type dispatch from DataType enum
    void submit_matmul_typed(
        DataType dtype,
        const void* A, const void* B, void* C,
        size_t M, size_t N, size_t K
    ) {
        switch (dtype) {
            case DataType::FLOAT32:
                submit_matmul(
                    static_cast<const float*>(A),
                    static_cast<const float*>(B),
                    static_cast<float*>(C),
                    M, N, K);
                break;
            case DataType::INT8:
                submit_matmul(
                    static_cast<const std::int8_t*>(A),
                    static_cast<const std::int8_t*>(B),
                    static_cast<std::int32_t*>(C),  // INT8 accumulates to INT32
                    M, N, K);
                break;
            case DataType::BFLOAT16:
                submit_matmul(
                    static_cast<const sw::universal::bfloat16*>(A),
                    static_cast<const sw::universal::bfloat16*>(B),
                    static_cast<float*>(C),  // BF16 accumulates to FP32
                    M, N, K);
                break;
            // ... other types
            default:
                throw std::runtime_error("Unsupported dtype: " + dtype_name(dtype));
        }
    }

private:
    template<typename Scalar>
    uint64_t estimate_cycles(uint64_t flops) const {
        // Throughput depends on dtype
        // INT8/INT4 can potentially be faster due to smaller operands
        constexpr size_t bits = ScalarTraits<Scalar>::bits;
        uint32_t ops_per_cycle = (bits <= 8) ? 1024 : (bits <= 16) ? 512 : 256;
        return (flops + ops_per_cycle - 1) / ops_per_cycle;
    }
};

} // namespace sw::kpu
```

## Key Design Decisions

1. **Accumulator in output**: For quantized matmul, C has accumulator type (INT32 for INT8 inputs)
   - Allows fused requantization at the end
   - Matches hardware behavior

2. **Unpacked computation**: INT4/FP4 are unpacked for computation, packed for storage
   - Simplifies kernel code
   - Q/DQ conversion at memory boundaries

3. **Universal for floats, native for ints**:
   - Use sw::universal for FP16, BF16, FP8, FP4 (accurate arithmetic)
   - Use native std::int8_t, std::int32_t (fast integer ops)

4. **Static type dispatch in compute fabric**:
   - Template kernels are instantiated at compile time
   - Runtime dispatch via DataType enum for Python bindings

## Design Decisions (Reviewed)

1. **Accumulator type**: Explicit in kernel signature as template parameter
   - `template<typename Scalar, typename Accumulator>` for same-type inputs
   - `template<typename ScalarA, typename ScalarB, typename Accumulator>` for mixed-precision
   - Enables energy/cost optimization by choosing accumulator precision

2. **Mixed-precision**: Two input type parameters + accumulator
   - Example: `matmul_mixed<float, int8_t, float>(activations, weights, output)`
   - Universal can provide up/down conversion adaptors when needed

3. **FP4 configuration**: `cfloat<4, 1, std::uint8_t>`
   - 1-bit exponent, 2-bit mantissa, 1-bit sign
   - Unpacked storage (1 byte per element)

4. **FP8 configurations**:
   - `fp8e5m2_t = cfloat<8, 5, std::uint8_t>` - 5-bit exp, 2-bit mantissa (like IEEE)
   - `fp8e4m3_t = cfloat<8, 4, std::uint8_t>` - 4-bit exp, 3-bit mantissa (NVIDIA)
   - `fp8e3m4_t = cfloat<8, 3, std::uint8_t>` - 3-bit exp, 4-bit mantissa
   - `fp8e2m5_t = cfloat<8, 2, std::uint8_t>` - 2-bit exp, 5-bit mantissa
