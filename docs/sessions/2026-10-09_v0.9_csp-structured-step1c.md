# v0.9 The Structured CSP Program: L0 Reclassified, Step 1c.1 (Stream and Symbolic Validation)

**Date:** 2026-10-09
**Version:** v0.9
**Status:** Complete (1c.1); 1c.2 (L-CA from the stream) next
**Tests:** test_csp_structured 6/6; test_csp_language, test_csp_program, test_csp_driver unchanged
and passing; full suite in the PR

## 1. Summary

The architect asked what an L0 matmul looks like, and on seeing one observed that L0 is not a
program but a trace. Its tile sequence is fully unrolled, so a 1M x 1M matmul (about 3 x 10^13
tile ops) cannot be written in it.

I noted that the step-1 CSP IR had the same property: the compiler unrolled the language's
loops, the driver enqueued every action, and the validator walked every statement.

Decided:
- L0 is reclassified as an instance/trace format, and the `.csp` program is the portable program
  (ADR 0004 §4, amending ADR 0001 D1);
- step 1c comes before the linear operator.

## 2. Decisions

- **One walker, two sinks.** The concrete semantics live in one place, `Walker`, which runs the
  AST incrementally. The trace (`compile()`) and the stream (`ActionStream`) are sinks of the same
  walk, so they cannot drift. The existing language tests pass unchanged on the rebuilt compiler.
- **Symbolic validation over families, with balanced loops checked once.** The language has no
  conditionals and affine indices, so every iteration has the same structure. Checking one
  representative iteration is sound when loop bodies are residency-balanced, because iterations
  then cannot collide. Cross-iteration residency (double buffering) is refused by name and still
  runs through the walker; proving it needs symbolic shift reasoning, a later step.
- **Conservative where unprovable.** "May overlap" and "not provably resident" are refusals. The
  walker (concrete) remains the authority on what a program does; the validator only ever says
  less than it can prove.
- **L-CA from the stream is 1c.2.** The driver seeds L3 entries with consumer counts at the Load,
  which needs lookahead. Making Release an executor action removes the lookahead, but it is an
  executor protocol change, so it is its own PR.

## 3. Verification

- The stream equals the trace action for action (kind, tile, process, accumulate, residency) for
  matmul in two forms and for LU. The buffer never exceeds one statement's actions.
- L-B over the stream equals L-B over the trace, and both are bit-identical to the reference.
- Symbolic validation equals the trace on peak L3, loads, calls and stores for rectangular nests.
  LU is validated, and its totals are left out (triangular loops).
- **1M x 1M matmul:**
  - validated in about 0.05 ms;
  - peak L3 is 2;
  - loads, calls and stores are exactly 2n^3, n^3 and n^2 for n = 32,768;
  - the first million actions stream with a bounded buffer.
- The symbolic validator refuses, by line:
  - an index that may run off the edge;
  - a family that may overlap a resident one;
  - an unbalanced loop;
  - a read that is not provably resident;
  - capacity, from family sizes (a 1M B column panel is 32,768 tiles).

## 4. Review (CodeRabbit, three findings, all fixed)

- **ADR 0004's "Preserves" row still said ADR 0001 D1 stands.** It now preserves only D5 (values
  answer to the L0 reference).
- **Major: the validator accepted programs the walker refuses.** The loop-balance check compared
  only resident families. A body checked once could consume state it found: storing an
  accumulator closed before the loop, or storing a tile written before it. Both work in the first
  iteration and fail in the second, and validate() reported success with wrong totals. A loop now
  must leave every accumulator it found, and every tile dirty on entry must still be dirty.
  Clean-to-dirty stays legal, because LU writes `A[:, :]` in place inside loops.
- **My never-fed test was a capacity test**, since its operands overflowed L3. It now exercises
  the rule twice: a loop that never runs, and `0..j` at j = 0.

## 5. Wrong Decisions

- **Step 1's compiler unrolled the language into a trace, carrying L0's limit into the new
  layer.** The architect's reading of L0 exposed it. Lesson: a program representation has to be
  checked against the largest problem it claims to express, not only against the tests'.
- **`ActionStream` first held a reference to its AST, and the tests passed a temporary.** That
  dangling reference made the stream read freed frames. The stream now owns its program.
