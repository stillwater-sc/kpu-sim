# v0.10 The Floorplan View, Overview (#447)

**Date:** 2026-11-16
**Version:** v0.10
**Status:** in review (PR, based on #451's branch). #447 can close with it. The Investigate view
is #448, and publishing is #449.

## 1. Summary

The first view of ADR 0005's viewer suite: `tools/visualization/floorplan/`. It draws a
`kpu-structure` record (#451) from either producer, the model's or the RTL generator's. The
scope is esg#59's Overview view, moved here as #447: layers, die size and its breakdown, an
inspector, dropping a file. Its local server is not part of it: the viewer needs none, and the
service is #449.

## 2. Technical Decisions

- **Decision 1: one page, no dependencies, the tile-flow viewer's conventions.** Plain HTML and
  SVG with the same palette tokens, light and dark themes, and an embed marker for `pack.py`. It
  works offline, which esg#59 asked for, without vendoring a library.
- **Decision 2: it reads only `kpu-structure` v1.** A floorplan of either older format is refused
  on the page, with the converter to use. `pack.py` converts one on the way.
- **Decision 3: draw what the record holds.** No geometry or route is invented. Networks draw
  their recorded points. An estimated floorplan says whose estimate it is.
- **Decision 4: labels are readable or absent.** A leaf is labelled in its middle, 9 to 16
  screen pixels. A container gets a small label in its top-left corner, and none where a child's
  corner label would sit on it. Every label is sized in screen pixels, so zoom keeps them legible.
- **Decision 5: Compare is a second record**, not a stored history. Esg#59 asked for "the change
  from the previous run"; a second file is the previous run, and nothing persists in a browser.

## 3. Issues Encountered

- Found by rendering the page headlessly and reading the screenshots:
  - The network nodes were drawn as huge rings: each circle inherited its group's 2-unit stroke,
    in mm. They have no stroke now.
  - Containers' labels covered their children ("checkerboard", "array", "CPU").
  - Long provenance values overflowed their panel.
- **A string-concatenation bug** in a label's x position: `X(x) + fs * 0.4` inside string
  concatenation joined two numbers as text. Chromium reported the invalid attribute, and the
  headless check failed on it.

## 4. Wrong Decisions

- None.

## 5. Verification

```bash
python3 tools/visualization/floorplan/test_viewer.py tests/program/structure    # 6 tests
```

- `pack.py` embeds every sample, and its payload parses back to the record; a non-record exits 2.
- In headless Chromium, for each of the three samples:
  - one rectangle per placed block, and one path per link;
  - a click fills the inspector;
  - a network's checkbox and the presets hide what they say;
  - zoom changes the view and Fit restores it.
- Compare shows the die-area change. Another format, or version 2, is refused on the page.
- A record whose label, notes and configuration carry markup and script injects nothing: it shows
  as text.
- Both themes rendered with no script error. The screenshots were checked by eye.
