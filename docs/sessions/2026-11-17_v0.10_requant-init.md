# Session: the full int8 epilogue, generated (#395)

**Date:** 2026-11-17
**Version:** v0.10 (in progress)
**Issue:** #395 (the generator's requant + init gap, found 2026-11-16)

## 1. Summary

`kpu-csp-gen` refused `--requant` with `--init` ("requant with an init is not built yet"), so
C = scale(A . B + bias) could not be generated for any dataflow. The rest of the stack already
handled it: the generator declared D and b in the accumulator's type, the fabric's init (os) and
the Combiner's MERGE_INIT (ws, is) add it, and the scale runs on the store (os) or the final merge
(ws, is). The refusal is lifted for bias and bias-row. Accumulate stays refused.

## 2. Technical Decisions

- **Lift, do not rebuild.** I lifted the refusal in a worktree first and ran all 12 combinations
  (os/ws/is x bias/bias-row x a uniform or per-channel scale) at every level. Every level agreed
  with L-B, so no emission change was needed.
- **Check L-B against an independent reference, not only the levels against L-B.** The new test
  computes the int32 matmul unrequantized, adds D[r, c] or b[c] the way an int32 register does
  (wrapping), and scales in double precision, ties to even, saturated. That is the method the
  existing bias and per-channel tests use.
- **Size 16, one K block.** Here a ws or is tile's first merge (which adds the init) is also its
  final merge (which scales). The test covers it, so the order init-then-scale is checked where
  it is easiest to get wrong.
- **Accumulate stays refused.** C += A . B onto an int8 C would add a scaled result to an unscaled
  sum. Its message now names it: "requant with init accumulate is not built yet".

## 3. Issues Encountered

- `--requant` takes `m,shift`. The first sweep passed the flag bare, and every program was refused
  before it was generated.

## 4. Wrong Decisions

- None.

## 5. Verification

- New tests: `Requant: an init before the scale, on every dataflow and level` (362 assertions,
  24 programs, every level bit for bit against the reference) and `Requant: an accumulate init is
  still refused, by name`.
- gcc and clang `release-werror`: the full suites.
- `kpu-run --level all` on S1 with a Combiner, all 12 combinations at 64/16 and 6 at 16/16: every
  level computes L-B's values, and the records check clean.
