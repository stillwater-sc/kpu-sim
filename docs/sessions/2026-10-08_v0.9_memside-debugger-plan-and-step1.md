## 1. Summary

After merging DRAM step 3 (#332), the architect asked for DRAM step 4 and a debug page for the
memory side, with the NoC ports stubbed. A survey showed why this needed a design first:
- `.tflow` is produced only at L-T1, which has no banks.
- The hosted LPDDR5 controller's trace lacks the row and is private to the bridge.
- The burst path emits nothing.

The plan, `docs/plans/memory-side-debugger.md`, has the decisions: Q1-Q5 all as recommended.
Step 1 makes every DRAM command and every window burst observable.

## 2. Decisions

- **The `.mflow` record is separate from `.tflow`.** It holds a different grain (bursts and
  commands) from a different producer (the CSP memory side). It shares the container code.
- **Observation is a callback, not trace post-processing.** At the moment of issue the callback
  has the row and the request. Unset, it costs one null check per command.
- **Commands issue at the executor cycle being ticked to.** The bridge advances the controller
  in executor-cycle steps, so that cycle is exact to the executor's resolution. Later points
  (command end, data window) are converted at ticks-per-cycle.
- **The MC installs its sink lazily.** It captures `this`, and a test helper returns a
  controller by value.

### Addendum: step 2, the harness

- **Built:** `MemorySideHarness`. It wires the existing CSP processes standalone and stubs every
  NoC port: request models, a load sink with injection-bus pacing and input-queue
  back-pressure, and an ejection model into the store buffers.
- **A first test expectation was wrong.** I asserted an infinite sink would be 4x faster than a
  400-cycle bus. It was about 3x, because without the bus, DRAM sets the pace. The test now
  asserts what is true: the slow run is bus-bound, and the fast run reaches the DRAM ceiling.
- **Self-review before compiling caught two bugs:** the load-tag map was never filled, and
  unused members would fail clang `-Werror`.
- **Mutation checks:** a sink that never refuses, and a consumer that never frees L3, each fail.
