# v0.9 L3 Placement Is Behavior: Decided (l3-placement-at-lb step 1)

**Date:** 2026-10-11
**Version:** v0.9
**Status:** Complete (step 1 of 7: docs only)
**Tests:** not run (no code changed)

## 1. Summary

The #363 domain-flow debugger plan said "L-B models a capacity, not placement". The architect
ruled that wrong: tile placement in L3 is machine behavior, as loading an operand into a register
is for a CPU, and without it the CSP program's `resident` and `release` decide nothing.

Investigation found that no level executes a placement:
- L-B: a map from tile name to values, checked as a count (`behavioral.hpp`);
- L-T1: anonymous credits, so a Load takes whichever slot frees first (`transactional.hpp`);
- L-CA: `slot_id` from each DMA engine's own round-robin counter (`dma_engine_process.hpp`,
  `allocate_slot`), so T4's eight engines can give two live tiles the same slot id;
- the L0 trace: no L3 transaction at all.

The plan `docs/plans/l3-placement-at-lb.md` was written and approved with all six
recommendations (walker allocates by a named policy, default `fifo`; explicit override; trace
opset 1.2; interleaved banks; L3 first; L-B and the trace first).

## 2. Decisions recorded

- ADR 0004 §5 (amendment): L3 addresses at every level, allocated once by the walker; level 2
  sets the module.
- `csp-program-tile-sequencing.md` §2.1: "one flat L3" is one address space, not an unplaced pool.
- `tile-flow-debugger.md` Q2 ("pooled first") superseded.
- `domain-flow-debugger.md` (#363) committed as held, its §3.7 placement rule marked superseded.
- `CLAUDE.md`: the decision, and that it is not built yet, so a pooled L3 is never presented as
  the intended model.

## 3. Wrong decisions

- **I wrote a model gap as a design rule.** In the #363 plan I stated "L-B models a capacity, not
  placement" as an honesty rule, carrying forward the level-1 "flat L3" hypothesis and the
  tile-flow plan's "pooled first" without asking whether L-B should model placement. Lesson: when
  a plan states what a level does *not* model, check that the omission was decided, and flag it
  for review if not. Saved to memory as a standing rule.
