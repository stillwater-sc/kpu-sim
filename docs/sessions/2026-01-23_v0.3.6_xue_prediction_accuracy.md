## Technical Decisions

### Decision 1: Fix HardwareModel.peak_gflops

**Choice:** Changed `peak_gflops` from 1024 to 512 in `include/sw/xue/operational_analysis.hpp`

**Rationale:**
- 16x16 systolic array = 256 MACs/cycle
- Each MAC is a fused multiply-add (FMA) = 2 FLOPs
- Total: 256 × 2 = 512 FLOPs/cycle
- At 1 GHz reference clock: 512 GFLOPS

**Files Modified:**
- `include/sw/xue/operational_analysis.hpp:38`

### Decision 2: Fix CMake BUILD_TESTING State

**Choice:** Save and restore `BUILD_TESTING` around domain_flow FetchContent

**Alternatives Considered:**
1. Remove FORCE from set() - Rejected: domain_flow might still enable its tests
2. Use subdirectory-scoped variable - Rejected: CMAKE doesn't scope cache variables
3. Save/restore pattern - Selected: Clean, explicit, maintains user's choice

**Rationale:** The `DomainFlowIntegration.cmake` was setting `BUILD_TESTING OFF CACHE BOOL "..." FORCE` to prevent domain_flow tests, but this globally disabled all tests including kpu-sim's own tests.

**Files Modified:**
- `cmake/DomainFlowIntegration.cmake:46-67`

### Decision 3: Test Structure with Quick CI Subset

**Choice:** Two test targets per validation suite - full and quick

**Rationale:**
- Full test (`xue_prediction_accuracy`): All 28 assertions, 120s timeout
- Quick test (`xue_accuracy_quick`): Hardware + classification only, 30s timeout
- CI can run quick tests on every commit, full tests nightly

**Files Modified:**
- `tests/validation/CMakeLists.txt`

## Issues Encountered

### Issue 1: Test Executable Not Built

**Symptom:** `./build/tests/validation/test_xue_prediction_accuracy: No such file or directory`

**Root Cause:** `BUILD_TESTING` was globally set to `OFF` by `DomainFlowIntegration.cmake` when fetching domain_flow, preventing all tests from being built.

**Fix:** Modified `cmake/DomainFlowIntegration.cmake` to save BUILD_TESTING before setting it OFF, then restore it after FetchContent_MakeAvailable:

```cmake
# Save BUILD_TESTING state before fetching domain_flow
set(_KPU_SAVED_BUILD_TESTING ${BUILD_TESTING})
set(BUILD_TESTING OFF CACHE BOOL "Disable domain_flow tests" FORCE)

FetchContent_MakeAvailable(domain_flow)

# Restore BUILD_TESTING to enable kpu-sim's own tests
set(BUILD_TESTING ${_KPU_SAVED_BUILD_TESTING} CACHE BOOL "Enable testing" FORCE)
unset(_KPU_SAVED_BUILD_TESTING)
```

### Issue 2: Unused Variable Warnings

**Symptom:** Compiler warnings for `dram_bytes` and `expected_ai` variables

**Root Cause:** Variables computed for documentation/debugging purposes but not used in assertions

**Fix:** Removed unused variables from test code
