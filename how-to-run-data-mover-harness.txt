  Example Commands:

  # Assemble
  ./build/tools/development/kpu-assembler kernels/asm/matmul_16x16x16.kpuasm -o matmul.kpubin

  # Behavioral (fast, correct values)
  ./build/tools/runtime/kpu-loader matmul.kpubin --fidelity behavioral \
      --input-a A.bin --input-b B.bin --output-c C.bin --stats

  # Transactional (timing + trace)
  ./build/tools/runtime/kpu-loader matmul.kpubin --fidelity transactional \
      --input-a A.bin --input-b B.bin --output-c C.bin \
      --trace trace.json --stats -v
