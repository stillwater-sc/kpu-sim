The Problem: SIMT threads compute independent dot products. Each thread fetches its own A row and B column from the register file. For a 1024³ matmul: 3 billion RF accesses (N³ scaling). The register file becomes the energy bottleneck.

The Solution: Systolic schedules reuse operands as they flow through. Each A element is used by 16 PEs (one row). Each B element by 16 PEs (one column). For a 1024³ matmul: ~2 million L1 reads (N² scaling). That's 1500× less data movement than SIMT.
